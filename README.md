# ⏰ Digital Clock Web Application

This is a simple and elegant **Digital Clock** project built using HTML, CSS, and JavaScript. It displays the current time in a 12-hour format with AM/PM icons and a stylish, responsive UI.

---

## 🌟 Features

- Real-time clock updates every second
- Responsive and modern design
- AM/PM icon switch (☀️ for AM, 🌙 for PM)
- Beautiful animated background
- Lightweight and fast

---

## 🔧 Technologies Used

| Frontend | Description            |
|----------|------------------------|
| HTML     | Page structure         |
| CSS      | Styling and layout     |
| JS       | Time logic and display |
